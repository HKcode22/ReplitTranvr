## A. Source allocation — combine rather than replace

| Function | AeroDataBox / RapidAPI | ADSB.lol / ODbL |
|---|---|---|
| S1 provider-observable departure flight population | **Primary**: role-aware airport FIDS with frozen query/source, original available-at, append-only membership | **Never a substitute census/denominator**; a tracked aircraft is not by itself a scheduled operating flight |
| PRE flight selected T and prediction cutoffs | First independently verified provider-native schedule milestone (not generic `scheduledTime` until certified); frozen first observation | No scheduled flight T guaranteed; live/historical ADS-B observations arriving **after** a cutoff cannot backfill PRE |
| AIRBORNE optional aircraft state | Webhook/status/location from verified AeroDataBox sources, with source and receipt clocks | **Complement**: live positions, trajectories, MLAT/ADS-B metadata, independent receiver evidence when as-of and verified flight-to-aircraft linkage meet source/rights controls |
| Actual-only takeoff/landing outcome | Use only externally qualified per-record source and actuality semantics; FIDS `runwayTime` can be actual **or estimated** | Aircraft position and vertical change can support **inferred takeoff windows/proxies**, not exact actual-only wheels-off labels without independent calibration/certification |
| Scope, bias and data science | Original FIDS denominator, unknown codeshare/operating leg, inside/outside capture, outcome missingness by strata | Measure position coverage/link success/age and receiver bias **separately** against that same FIDS denominator; do not create an ADSB-only hidden training population |
| Rights | Provider's account-specific Contents / cache/retention, including Nov7 rules, independently confirmed before retention | ODbL attribution/share-alike obligations and service operator's production-use coordination, plus any feasible individual data-retention/privacy conditions |

Provider sources:
- Official [ADSB.lol API and explicit production coordination](https://api.adsb.lol/docs): free/open v2 positions, ODbL 1.0; asks prospective production users to contact service operator.
- Official [ADSB.lol historical daily archive](https://www.adsb.lol/docs/open-data/historical): aircraft traces with latitude/longitude/altitude/groundspeed/vertical rate and ADSB/MLAT/TISB origin, ODbL 1.0.
- Official [AeroDataBox ADS-B-derived runway detection limitations](https://aerodatabox.com/flight-take-off-and-landing-time-runway-detection-based-on-ads-b-data-more-flights-and-status-updates/): retroactive, partial coverage, not guaranteed even at covered airports; 2020 airport examples must not be treated as current WSSS guarantee.
- [Provider-native T and actual-only semantics issue #200](https://github.com/HKcode22/ReplitTranvr/issues/200), [per-flight rights #300](https://github.com/HKcode22/ReplitTranvr/issues/300), [full prospective cohort #293](https://github.com/HKcode22/ReplitTranvr/issues/293).

## B. Current implemented code and exact limits (no hidden live replacement)

- `server/lib/disruption/gate05ZeroCostAdsbEvidence_v39.ts`: existing no-IO WSSS ADSB.lol v2 point normalization, fresh/coordinate/source-clock guards. **Strengthened in this PR**: as-of eligibility demands BOTH the system receipt timestamp and approximate provider position-observation timestamp at or before the cutoff. The latter is derived from provider now minus seen_pos and must never be represented as an exact runway event time.
- `server/lib/disruption/gate05LiveAdsbContinuity_v39.ts`: count repeated aircraft candidates, implausible jumps and gaps; still NOT canonical operated-flight matching or runway certification.
- `scripts/v39_gate05_adsb_lol_wsss_one_free_get_20261029.ts` and `scripts/v39_gate05_adsb_lol_wsss_bounded_live_20261029.ts`: **historical, sunset, finite** source research only. No resident ADSB.lol production polling, no Oct/Nov2 GitHub schedule impact.
- `server/lib/disruption/gate05RunwayDelayLabelAudit_v39.ts`: exact runway label assessor. Added explicit `ADSB_INFERRED_TAKEOFF_PROXY` evidence class, which MUST return `SOURCE_SEMANTICS_UNVERIFIED` and `runwayDelayMinutes=NULL` for the exact runway target even when someone passes an alleged external authentication flag. Generic scheduled departure cannot stand in for scheduled wheels-off.
- `server/lib/disruption/phase4Gate5DualSourceAdsbAdmission_v39.ts`: NEW **pure optional AIRBORNE-admission assessment**. Requires source position and receipt both <= decision time, independently proven AeroDataBox operated leg and aircraft correspondence, no known aircraft swap/conflict, and independently reviewed ODbL/retention conditions. A callsign-only or transponder-only join is refused. Always returns `certifiedActualOnlyWheelsOff=false` and `productionSourceActivationAuthorized=false`; NO network/DB.
- `server/lib/disruption/phase4Gate5LabelObservabilityBiasAudit_v39.ts`: NEW **pure offline denominator/label missingness diagnostic**, subgrouped by airport × tier × horizon, unique flight-horizon digest. Reports FIDS population, eligible/persisted PRE, captured webhooks, exact-label-reported, proxies, estimates, pending/missing; `NULL` for zero denominator; only descriptive coverage disparities, NOT proof of zero selection bias or permission to weight/resample. An authenticated actual label must be independently verified BEFORE this descriptive aggregator can receive that status.
- `tests/phase4_gate5_dual_source_adsb_admission_v39.test.ts`, `tests/phase4_gate5_label_observability_bias_audit_v39.test.ts` and updated existing Gate05 tests cover postcutoff rejection, duplicate/unknown/identity, proxy-as-actual rejection, protected licensing and no I/O. These are **offline code checks, not live scientific evidence**.

## C. Next production/validation milestones — BEFORE a combined source can be certified

1. **Preserve Nov2 current 9-slot FIDS aggregate experiment unmodified.** T−24h successful 3/3 and six measured API units; exact future T−6h/T−90m only at their frozen clocks. This is a source shape pilot with zero per-flight original or stored PRE, not a completed Gate5 cohort. Its missing `runwayTime` 24h in advance is expected and not an excuse to redo T−24h.
2. **Identify exact matched denominator and as-of join:** freeze AeroDataBox operating-leg identity and schedule-version lineage from a legally permitted retained original; only then associate ADSB.lol `hex`/callsign/registration and origin-local time through independently evaluated matching evidence. Prevent aircraft swaps, multiple flights same callsign, same aircraft adjacent legs, source clock skew and duplicate position observations.
3. **Validate ADSB.lol availability and production permission** across representative airports/time-of-day; do not assume a one-off WSSS public point GET is a continuously reliable source. Review ODbL attribution/share-alike and its explicit production-use coordination. Consider historical archive retention licensing separately; never silently merge database licenses or overwrite AeroDataBox Contents expiry.
4. **Protect time:** distinguish `position_observed_at`, approximate server/seen_pos timestamp, `http_received_at`, durable `available_at`, AIRBORNE state observation vs deployable prediction cutoff, and true postflight outcome time. Preflight source requests cannot certify a postflight actual runway event. Sample and retention horizon must be legitimate before creating features.
5. **Verify actual labels:** seek provider-native **actual-only per record** (and separately proven scheduled wheels-off baseline) or externally validated takeoff/landing measurement for the same canonical leg. Until then, trajectory threshold-crossing is `ADSB_INFERRED_TAKEOFF_PROXY`, modeled in separate sensitivity/auxiliary analysis, never target ground truth.
6. **Measure missing-not-at-random risks** by selected airport/tier/region/UTC bucket/airline/known-tail/source availability/receiver coverage, compare coverage and error on an independently validated sample, record raw capture gaps, evaluate conditional performance/calibration and uncertainty by stratum. No promise of zero bias; pre-register group contrasts/minimum counts/robustness before training.
7. **Connect tested production services** to real lawful FIDS source storage, physical operating-leg matching, durable PRE snapshot builder, AIRBORNE optional source adapter, terminalized outcomes, cohort-scoped independent read-only audit. Freeze code+manifest/protocol versions, verify all Plan f.8 prerequisites then seek explicit Phase5/Phase6 authority. A pure helper or green CI does not finish this milestone.

**Boundaries:** NO Cloudflare, Replit Agent, always-on Replit scheduler, paid dispatch, new GitHub timed worker, telemetry secret, provider replacement, or Phase6 activation is added by this supplement.
