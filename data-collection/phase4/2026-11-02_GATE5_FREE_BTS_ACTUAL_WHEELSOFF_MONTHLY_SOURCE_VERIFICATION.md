# Phase4 Gate5: concrete free U.S. actual wheels-off reference, official August 2026 data

The study owner requested practical FREE sources for scientific gaps without discarding the original f.8 §5–7 population/PRE/callback/POST methodology. This follow-up implements real *source availability* (not same-flight linkage) from the U.S. Department of Transportation Bureau of Transportation Statistics (BTS).

## Official source, limits, and construction

[Official BTS PREZIP directory](https://transtats.bts.gov/PREZIP/) lists the `On_Time_Reporting_Carrier_On_Time_Performance_1987_present_2026_8.zip` file (August 2026, published October 26 2026, archive approximately 32 MB). [BTS field definitions](https://www.transtats.bts.gov/Fields.asp?gnoyr_VQ=FGJ) describe `WheelsOff` as the aircraft's actual takeoff from the runway, while `DepTime` and `CRSDepTime` are **gate** departure clocks, not planned wheels-off. The data covers U.S. reporting carriers' non-stop domestic operations, with publication lag. This is free, publicly distributed U.S. government data. It cannot provide current WSSS/OMAA/SKBO/YSSY PRE source population or current month postflight runway truth and cannot prove a native scheduled-wheels-off T.

The one-shot GitHub Actions workflow `.github/workflows/phase4-gate5-free-bts-actual-reference.yml` is **not a scheduled paid experiment**. When merged to main it downloads **one official archive** from the exact predeclared URL, with no credentials, and requires source archive size <45MB, uncompressed CSV <600MB and ≤1 million rows. It streams original CSV using Python 3.11 standard library (`zipfile`, `csv`) with **mandatory exact field names**, strict U.S. reporting month, airline/flight/airport, canceled/diverted and source HHmm controls. It outputs only **anonymous aggregate source-field availability**, SHA256 of the official archive and explicit limit fields; no airline/flight raw rows in Actions logs. It uploads the original publicly downloadable government archive plus aggregate JSON as a **2-day ephemeral GitHub artifact**, then an independent second GitHub job downloads the artifact and recomputes the entire ZIP/hash and aggregates for reproducibility, without any second external request.

All source rows counted as `actualWheelsOffRows` indicate BTS *reported* actual runway-off fields for historical U.S. flights; these have **not been independently matched to any AeroDataBox physical operating leg**. The source's `CRSDepTime` is scheduled *gate* time, not original V3.9 f.8 selected scheduled wheels-off T. An actual wheels-off record may be admitted as an independently verified outcome for a prospectively frozen U.S. reference cohort **only after exact date/carrier/flight/origin/dest/physical-leg identity, local-to-UTC timezone/date rollover/DST, and publication availability** checks. The existing typed guard `phase4Gate5BtsIndependentReference_v39.ts` covers those conditions; this PR verifies genuine official data availability and source schema, **not** yet the join. The script never creates PRE or backfills postflight knowledge into a predeparture cutoff.

Script: `scripts/v39_phase4_gate5_free_bts_aug2026_reference_actions.py`. Regression file: `tests/phase4_gate5_free_bts_monthly_source_v39.test.ts` invokes 1200-row **synthetic ZIP** selftest in Python; no live official network in tests. The GitHub main workflow itself performs the real one-off official public download.
