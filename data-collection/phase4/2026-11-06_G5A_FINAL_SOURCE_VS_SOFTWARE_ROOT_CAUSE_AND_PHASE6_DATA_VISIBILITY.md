## 5. Newly repaired Phase6 callback fail-closed path — separate production PR under review

**Concrete software defect discovered in this review:** `aerodataboxLimiter_v3.ts::defaultWebhookUrl()` can create a subscription callback URL with no `/:secret` when `AERODATABOX_WEBHOOK_SECRET` is absent (or fall back to a generic host when no published origin is given). But `routes_v3.ts::webhookIngress` requires the private secret and refuses the secretless route. The first Phase6 parent subscription creator in `adbCollectionController_v3.ts` and later child segment creator in `phase6SegmentActivation_v39.ts` called `createSubscription()` with no verified explicit URL. This leaves the potential to CREATE a provider subscription that cannot deliver usable responses. **This is software configuration safety risk on *future* Phase6 subscriptions, not the cause of G5A's FIDS-only observation zeros** (G5A never created subscriptions at all).

**Action:** [draft PR #412](https://github.com/HKcode22/ReplitTranvr/pull/412) introduces a pure fail-closed guard that requires an explicit HTTPS public origin plus 16+ character secret; validates path/credentials/URL and provides the authenticated URL to parent and child `createSubscription` calls. It refuses before provider mutation, does not modify existing G5A/DB/billing/manifest, and prints no secret. Focused offline [workflow #42333894511](https://github.com/HKcode22/ReplitTranvr/actions/runs/42333894511) completed **6/6 Vitest tests PASS** with **0 provider calls / 0 DB writes / 0 Phase6 activation**. Other crossrepo CI checks may remain pending, and the PR is draft until reviewed/merged. This does **not** verify that a hosted Replit receiver is reachable; separately prove that at Phase5, without sending real paid notifications unnecessarily.

The [Phase5/6 column observability script](audits/phase5-phase6-column-observability-readonly.mjs) has been pinned in the same doc-only PR. It is read-only and reports table column names/types and capped recent row presence. **Its production behavior has not yet been independently executed**; it is not an existing web dashboard or a legal license to retain raw data.
