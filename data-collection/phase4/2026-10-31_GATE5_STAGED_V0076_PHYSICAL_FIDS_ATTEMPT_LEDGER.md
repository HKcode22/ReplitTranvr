## Implemented in staged migration

- \`migrations/staged/V0076__phase4_gate5_logged_physical_fids_attempt_owner_v39.sql\` adds **only** new LOGGED metadata tables: immutable cohort SHA with global REST budget counter; exact frozen horizon owner and GitHub run ID; query+cutoff plans, and immutable per-physical-attempt journal. **No source payload, identifiers of individual flights, human PII, secrets or HTTP calls.**
- \`clean.reserve_phase4_g5_fids_physical_attempt_v39\` acquires locks in **global cohort budget → exact ACTIVE GitHub owner → exact source query** order. It requires the exact manifest, job run ID, query SHA, sequential attempt and canonical reservation SHA; checks the actual DB clock against planned dispatch and **cutoff−15min**, owner expiry, globally shared cohort REST-unit ceiling, and only permits up to three physical attempts per query. It atomically increments spent/reserved units and commits an immutable attempt receipt. **The caller must COMMIT the reservation before network GET, and an ambiguous request is never refunded.**
- It rejects an unknown or foreign GitHub run, owner that was not recorded as prearmed, missing/duplicate queries, out-of-order retries, overspending, early/late physical starts, and fabricated reservation hashes. A test-only owner is created solely on disposable PG16. No production owner/rights certificate is created here.
- **No new runtime privileges are granted.** Tables/functions have PUBLIC privileges revoked, and the SECURITY DEFINER reserve function has a restricted search path using only PostgreSQL built-in SHA256; a future production installer must review and grant execution narrowly to the exact service role for an approved cohort. No boot migration auto-applies V0076, and no historical data is altered.
- New main-push GitHub workflow \`phase4-gate5-staged-physical-ledger-disposable-pg16.yml\` installs V0076 to a **fresh, isolated PostgreSQL 16 container**, executes \`tests/sql/phase4_gate5_staged_physical_attempt_ledger_v39.sql\`, and tears it down. The test proves first two exact reservations, duplicate/foreign-run denial, project-budget exhaustion and immutable no-refund behavior. Focused Vitest regression tests verify no hidden production grants or provider secrets.
