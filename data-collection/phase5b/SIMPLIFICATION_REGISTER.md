### How to close an S item

Record the exact old dependency eliminated, test (positive and refusal), measured reduction or simple count (scripts/credential copies/calls/retries/round trips), exact deployed SHA or owner receipt, and remaining scientific boundary. Candidate = code exists, tested = exact test observed, deployed = actual runtime evidence, accepted = prospective consequence observed where needed. Never count a proposal or documentation link as eliminated code. Link to existing F/I/T rather than proliferate mandatory gates; add a new F only for a distinct evidenced cause.
