# Stored SOURCE one-shard publication and recovery

New actual composition of the existing V0095/V0098 query publisher, independently authenticated restricted query reader and registry-LAST writer. Takes one externally signed exact registry and up to 96 ordered signed query packets; validates all signatures/stable study pins/registry identity/packet envelope/retention against actual DB clock before writing. Existing committed rows are independently read and checked byte-for-byte; no overwrite or reinsert. Requires explicit independently reviewed recovery mode for partial/existing shard, publishes only confirmed absent query rows then registry LAST; refuses missing constituents of already committed registry rather than backfill. Unknown commit stops this invocation; disposable PG16 test simulates actual committed write with lost acknowledgement, fresh independent read resolves it before remaining inserts. Registry readback returns actual committed/observed DB time for later separately signed index, not a pre-signed invented future timestamp. No new role/schema, provider GET, GH dispatch or signing key in the implementation. Synthetic transport test does not prove actual Stage7/8/9, actual provider rights or paid admission. Still requires the real approved protected packet producer/signing policy and runtime publisher entrypoint; no production data, production configuration or migration in this PR.
