# Restart-safe SOURCE publication (no provider, no GO)

V0098 stores the original query review wire, but not registry wires. Recovery reconstructs the precise independently approved day from the saved draw and prepared ledger, then checks the entire bounded private packet set in a fresh restricted-reader snapshot. Existing query bytes and original wires must match and verify. Missing rows receive new signatures at the current DB clock, with expiry no later than the existing shortest review. Existing registries receive an explicit **fresh re-attestation**, never a fabricated historical signature or a repeated insert. The original registry commit clock and independent review metadata remain unchanged. The index verifier checks this distinction and registry-last ordering. Initial index claims, expired or late requests, any changed payload, wrong key, missing constituent or extra row are hard holds. The recovery path requires independently approved exact policy and daily packet plus explicit recovery approval. No new DDL, prod release, paid authority or provider requests. Production runtime commissioning, signing authority, and dynamic daily packet production remain separate.
