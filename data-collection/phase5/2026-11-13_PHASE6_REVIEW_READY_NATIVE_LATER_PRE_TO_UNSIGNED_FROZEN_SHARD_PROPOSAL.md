## New missing-link implementation (deliberately does not sign/publish)

[`phase5ReviewedLaterPacketToUnsignedDayRegistryProposal_v39.ts`](../../server/lib/disruption/phase5ReviewedLaterPacketToUnsignedDayRegistryProposal_v39.ts) accepts **the literal earlier source day registry JSON byte string plus a separately approved exact source registry SHA**; same-day manifest, rights/release, reviewed code SHA, named prospective registry path and exact shard index; and 1–96 existing `P5ReviewReadyLaterPrePacketBytes` objects with the separately expected review-artifact SHA and future private packet path.

It checks complete prior source-registry bytes and unique source query digests, validates each review-ready packet's zero-privilege/NO-GO flags and exact packet byte SHA/JSON, checks actual source query is among prior independent SOURCE day registry entries, same run-day/manifest/code/rights/release, real original SHA/population UUID/physical leg evidence hashes, exact canonical UTC selected native T, real T24 witness SHA binding (recomputed via the existing Stage17 digest function) **or** separately approved explicit T24-missing protocol, refuses duplicate flight×horizon, duplicate SHA/review artifact/path, and refuses >96 without truncating. Sorts by exact own PRE cutoff, then immutable flight ID and path. Builds **in-memory only** wire-compatible future registry JSON and sha256 plus exact per-packet bytes for the independently authorized reviewer/publisher.

Although the historical wire schema is named `v39.phase5.signed-later-pre-day-registry.v1`, its **in-memory candidate** does *not* mean it is signed. The outer status is `REGISTRY_PACKET_BYTES_FOR_INDEPENDENT_EXTERNAL_SIGNATURE_NOT_PUBLISHED` and `independentlySignedRegistry=false`, `existingRegistryVerifierCalled=false`, `flightFilesPublished=0`, `registeredV0091Tasks=0`, `providerCalls=0`, `databaseWrites=0`, `githubDispatches=0`, `phase5ScientificFreezeGranted=false`, `phase6PaidGoGranted=false`. An external SHA supplied by a caller is not cryptographic proof of independent actor identity, signer authority or Contents rights. **No automatic self-signing; no GitHub writes, files, timers, SQL, provider or actual credential.**

The return contains private full flight IDs and packet bytes; do **NOT** stringify the bundle or put it in public CI/Action logs or unsecured GitHub artifacts. The separate `summarizeP5UnsignedLaterRegistryReviewPlan` only returns digest and aggregate counts and is suitable to display.
