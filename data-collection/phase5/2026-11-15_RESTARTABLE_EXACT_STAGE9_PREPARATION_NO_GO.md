# Restartable exact Stage9 preparation

Adds explicit authenticated EMPTY day detection to the existing initial prepared-ledger readback and a bounded resume port. A protected caller supplies an already independently verified durable review packet; Stage7/8 rederive its exact hashes, then the existing readback distinguishes complete zero/zero from an exact committed day or partial/corrupt/late/unauthorized state. Only authenticated zero/zero may enter original serializable Stage9 once; complete existing day is verified without any repeated INSERT. An unknown commit stops the invocation; next independently authorized run must re-read, not retry inside a failing call. Existing lock, ACLs, original cost checks and no-paid flags remain unchanged. This is a library port, not evidence that an external review authority or production runner exists. No new schema or paid calls. Regression added to actual disposable PG16 suite, existing default readback behavior unchanged.
