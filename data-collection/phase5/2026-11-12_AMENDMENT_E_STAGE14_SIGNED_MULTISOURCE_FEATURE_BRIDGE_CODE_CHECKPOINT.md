2. New [signed supplemental feature adapter](../../server/lib/disruption/phase5AmendmentESignedSupplementalFeatures_v39.ts) accepts a bounded bundle of **up to twelve extra features and 48 source observations** *already present inside the existing independently frozen and SHA-pinned GH flight packet*. It supports:
   - **Genuine bound-original FIDS fields**, only `operating_carrier`, `scheduled_arrival_utc`, `provider_revised_departure_utc`, `reported_pre_departure_status`. The observation's original response hash must match the **already joined real V0079 original** and its source-available time **exactly equals** the independently joined `clean.flight_population.available_at`; no second unbound FIDS reply or revised/scheduled-event substitution.
   - **NOAA METAR** origin visibility and wind with independently supplied receipt hash, recorded observation and receipt times, verified origin station identity and conservative ≤6-hour observation-age/≤30km metadata checks. A candidate from the wrong airport is refused.
   - **NOAA TAF** origin/destination flight-category **only if** reported issued before prediction and forecast validity covers the original selected native departure T; do not use destination weather as origin weather, an issued forecast as measured outcome, or TAF observations after issuance.
   - **Reviewed historical context**, prior-aircraft turnaround, prior-route and prior-airport median departure delay, airport congestion, with timestamped receipt, valid-from/to checks, source hash and source-available time. A historic-data database failure upstream is not legitimate missingness; reuse `historicalFeatureStore_v3.ts` to build audited source receipts, rather than treating an exception as an absent value.

The original [Stage14 writer](../../server/lib/disruption/phase5V0079SingleBoundFlightPreWriter_v39.ts) now optionally appends this supplemental feature set to the **existing source-bound origin/destination fields** and persists them via the existing `buildPreSnapshot` and `persistPreSnapshot`. No additional external API/Neon table or modified V0087–V0092 schema.

A packet containing supplements but lacking these gates fails **before irreversible queue WRITE_STARTED**. Nothing becomes implicitly armed or approved by the merge.
