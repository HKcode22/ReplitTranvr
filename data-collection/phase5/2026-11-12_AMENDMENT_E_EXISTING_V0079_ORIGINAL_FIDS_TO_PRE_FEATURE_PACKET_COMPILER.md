## Exact new compiler and safeguards

[`phase5AmendmentEFidsOriginalFeatureCompiler_v39.ts`](../../server/lib/disruption/phase5AmendmentEFidsOriginalFeatureCompiler_v39.ts) is pure and bounded (≤900 departure rows). It accepts a caller-provided **already read, unexpired** real stored FIDS envelope **and** the complete independently joined V0079 + normalized primary-member evidence. It checks:

1. The persisted `response_hash` matches the V0079 original binding, canonical JSON envelope checksum is **verified** (legacy unverified is insufficient), and stored original decoded provider body base64/length/SHA & departures arrays are verified by the existing Gate5 readback verifier. The decoded original-body hash must match the **independently joined** V0079 decoded-body hash, not a caller invented receipt.
2. Original request was explicitly a Departure for the original selected airport; recorded FIDS fetch time is no later than the bound normalized member DB availability.
3. There is **exactly one original departure row with matching positive provider-native `id`** (equal to independently joined `flight_population.provider_record_key`), codeshare is positively `IsOperator` or 1, operating flight number normalizes identically, origin+destination match the same normalized member, and original `departure.scheduledTime.utc` exactly equals the frozen selected native T. Unknown/no-ID and duplicate-ID cases **fail closed**, rather than inferring physical operating-leg identity from a flight number or schedule revision.
4. Emits only the bounded **four** supported FIDS fields from that one source row: `operating_carrier` (positive airline ICAO), `scheduled_arrival_utc` (arrival scheduledTime), `provider_revised_departure_utc` (provider revisedTime, **not actual gate-out**), `reported_pre_departure_status` (literal recognizable string only). Null, numeric/uninterpreted status, invalid or absent fields are **MISSING** and explicitly enumerated. Does not call an actual-time API or interpret `runwayTime`.
5. Output observation's sourceRecordId is the same real bound V0079 response hash, `observedAtUtc` is source `fetchedAtUtc`, `availableAtUtc` is real member `available_at`. The existing PR #593 as-of selector revalidates that no field was admitted *after* each forecast's actual DB issue time. The emitted bundle has source/content review receipt hash and frozen observation digest but **does not itself authenticate its reviewer, certify legal rights or produce a signature**.
6. Returns **no original body, flight number, provider ID, bytes or raw flight event** in its output. It only returns the limited feature bundle, unknowns and provenance hash; no provider call, database write or Phase6 activation.

Tests also pass this compiler's output through the **existing** Stage14 feature selector for a source-available T−6h issue and refuse tampering, duplicate source IDs, marketing codeshares, different normalized route/native T/number, source availability before fetch, and legacy body without canonical evidence.
