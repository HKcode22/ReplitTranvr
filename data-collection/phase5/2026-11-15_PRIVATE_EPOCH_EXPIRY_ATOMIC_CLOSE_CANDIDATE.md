# Private transport expiry candidate — Nov 15

Issue #413. Extends existing V0101 transport; no schema changes and no replay. The current-day reader intentionally refuses an expired newest revision instead of choosing an older live revision. Physically deleting only that head would undermine this guarantee. Existing day claims are permanent but carry no revision counter. The proposed owner operation closes an expired-head index chain atomically including any earlier still-live INDEX revisions, never deletes an unexpired packet, never deletes a claim and does not restart a closed day. This is an intentional early retirement of index bytes and requires explicit scope review; no production cleanup is authorized by merging code. Active jobs must be stopped before owner APPLY. Expired packet rows are selected by DB clock from the existing private transport. Inventory exposes only counts and a scope digest, not payloads, paths, hashes of individual rows or credentials. APPLY rechecks exact main, cutoff, scope and count in one locked transaction; unknown commit is not retried. Backup/PITR and provider ML-use permission remain separate, unverified gates. Existing raw-source retention reader and prior 65-object cleanup are not reused as deletion authority. Synthetic real PG16 test covers expired-head fallback, exact-scope mismatch, explicit approval, immutable claim and unrelated live day. No provider calls, production writes or paid GO by this PR.
