# Delegated SOURCE signing from exact independently approved prepared ledger

The new nonpaid signer accepts a separately externally SHA-pinned stable delegation policy (exact code, study, calendar/config/frame, rights, budget/grid, validity, query and registry key fingerprints) and the already existing externally reviewed exact daily Stage7/8/9 packet. It rederives the actual day via restricted database readback and independently verifies all initial committed V0079/V0082 rows before constructing and Ed25519-signing original SOURCE query and registry bytes under the approved delegated keys. No human or source-rights certification is inferred; actual policy/keys and protected runtime commissioning remain outstanding. Uses existing query/registry signature verification and returns sealed non-enumerable in-memory bundles to the existing registry-last publisher. No live keys, provider credentials or publication. Does not remove the existing daily approval packet; the independent prospective daily packet producer must still derive those inputs from the real frozen grid and reviewed policy. Synthetic test uses generated CI keys and actual disposable PG16 96-query prepared ledger.
