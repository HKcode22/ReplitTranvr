## 2. Semantics — explicit narrow supersession of Plan §4 wording

For this run only, the §4 exogenous reference means **observed commercial-airport movements/routes reconstructed from ADS-B**, not a published airline schedule feed.

The following wording is therefore frozen for §4.1/§4.5:

- traffic metric: `observed_commercial_movements`
- network degree: distinct observed resolved origin/destination connections with at least 53 movements in the fixed 365-day reference
- carrier diversity: upstream three-letter `Airline` ICAO operator field only; callsign prefix is diagnostic and is **not** silently substituted when `Airline` is missing
- international share: observed resolved departures where origin country differs from destination country / observed resolved departures with known country pair

The reference is **only an exogenous sampling/balancing reference**. It is not the Phase-6 population denominator and does not redefine the primary FIDS passenger-flight population.

Do not describe these quantities in reports as published scheduled departures, published scheduled routes, or passenger counts.

## 5. Known limitations — frozen, never hidden

1. Upstream release notes state **2026-05-05 through 2026-05-07 are missing or considerably incomplete** because of ADSB.lol archiving problems. No imputation is performed. The gap is recorded in reference provenance and diagnostics.
2. Coverage follows the ADSB.lol receiver network and is not guaranteed globally complete.
3. The upstream project documents occasional route/track ambiguity and possible duplicate flights; linking was improved from 2025 Q2 onward but is not perfect.
4. The reference may include operator-coded commercial movements that are not passenger flights. This is acceptable only because this artifact is an exogenous airport-traffic/balancing reference, not the primary passenger population denominator.
5. Ambiguous origin/destination records are excluded rather than guessed. The route validator prefers exactly two ICAOs from callsign-route validation; otherwise it requires exactly one origin and one destination ICAO from the track assignment.
6. Missing/invalid operator rows never receive a callsign-prefix substitution for the primary carrier-diversity metric.

## 6. Frozen traffic-tier rule

Tiering is a **project sampling stratum**, not an industry airport classification.

Sort all tier-verified reference airports by:

```text
(traffic_metric_value DESC, ICAO ASC)
```

Freeze the following rank shares:

- **HUB:** top **5%**
- **MID:** ranks after HUB through cumulative **30%** (next 25%)
- **REGIONAL:** remaining **70%** among reference-covered, tier-verified airports
- missing reference: `UNCLASSIFIED`, never coerced to REGIONAL

For the validated 2,295-airport candidate this produces:

- HUB = 115 airports; HUB boundary = **64,152 observed movements**
- MID = 574 airports
- REGIONAL = 1,606 airports

Why 5% HUB is frozen: WSSS ranks 31/2,295 and OMAA ranks 104/2,295. Top 4% would exclude mandatory OMAA; top 5% is the smallest whole-percentage rank cut that contains both mandatory yield-reference airports and retains HUB representation in all six macro-regions.

HUB region counts at the frozen 5% cut:

- North America 46
- Europe 36
- Asia-Pacific 22
- Gulf/Africa 4
- Oceania 4
- South America 3

The cumulative 30% MID boundary is frozen to create a broad middle stratum for the Plan's 1-HUB / 2-MID / 1-REGIONAL batch mix while preserving the majority long-tail population as REGIONAL. No Phase-6 yield, delay, weather, outcome or probe result enters this tier assignment.
