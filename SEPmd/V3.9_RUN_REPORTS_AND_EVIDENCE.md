# V3.9 Run Reports and Evidence — active external evidence ledger

> This file is intentionally separate from the Implementation Log. Append actual run/gate reports here so the Implementation Log remains a readable execution/status manual. This file never overrides the binding V3.9 Plan or the current Implementation Log.

## Rules

1. One immutable report block per `RUN-*`, `GATE-*`, `AUTH-*`, `ISS-*`, or `DEC-*` evidence ID.
2. Never rewrite an old report to make a later run look successful. Add a superseding record that references the original.
3. Do not store secrets, authorization headers, full credentials, or unrestricted raw provider payloads here.
4. Every report records repository commit, schema/config/provider pins, authorization ID when applicable, UTC times, exact command/interface, sanitized arguments, exit code, balances/units, subscriptions, failures, settlement reads, stop reason, result, artifact locations, and SHA-256 hashes.
5. The Implementation Log only receives the evidence ID/hash/path, current status, unresolved issue, and next permitted action.
