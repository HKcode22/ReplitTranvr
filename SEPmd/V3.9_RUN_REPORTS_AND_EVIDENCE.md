### Plain explanations for this session's work

- **Persistence writers** = functions that turn a built prediction row into a SQL INSERT. They take the database handle as a *parameter* (called "dependency injection") so tests can pass a fake that just records the SQL — proving the SQL is right without touching your real database.
- **`ON CONFLICT DO NOTHING`** = "if this exact row already exists, skip it silently." Makes writes safe to retry/repeat (idempotent).
- **PRE counters** = the 11 numerators/denominators §1.5.3 demands (population, eligible, expected, created, captured, features, targets, legs). Rates are computed, never stored — and a zero denominator yields NULL + reason instead of a lying 0%.
- **Tail fallback chain** = which aircraft identifier to trust, in order: painted registration first, then Mode-S code, then ICAO24 hex, then provider ID only if verified. `tailKnown=true` only for a real registration.
- **Structural order test** = a test that reads `routes_v3.ts` as text and asserts the raw→events→upsert→2xx call order. Weaker than a live integration test, stronger than nothing: it catches accidental reordering.

## 10. What AUTH Is and Why We Need It

### AUTH ≠ API key

| Thing | What it is | What it lets us do |
|-------|-----------|--------------------|
| **API key** | A credential to talk to AeroDataBox | Call the API (read balance, query flights) |
| **AUTH record** | A formal, time-boxed, scoped approval | Spend credits / create subscriptions / refill |

### Why the system demands it

1. **Protects your credits** — an AUTH caps spend and duration.
2. **Audit trail** — every paid action is traceable to an approval.
3. **Scope limiting** — names the exact airport/filter/window, ceiling, stop owner.
4. **Automatic stop** — refuses when AUTH expires or a ceiling is hit.
