- `clean.raw_delivery`: raw body/request/response/path/errors plus provider subscription/publication/delivery/notification/attempt/cost facts;

### 3.3 FIDS evidence verifier tightened

The retention-matrix verifier no longer accepts contradictory FIDS wording by taking the shortest time mentioned. It now parses **all explicit hours/days** for the FIDS row and blocks if:

- no parseable lifetime is supplied; or
- **any declared class-specific lifetime exceeds 24 hours**.

Thus a statement such as `24 hours for FIDS, but 7 days generic raw retention` cannot accidentally satisfy the FIDS-specific proof row.

These are promoted to `expiry-covered` only after an explicit owner exists and CI validates the implementation.

### 4.2 Newly discovered canonical-ID issue

Audit found an additional copied field: `clean.raw_delivery_item.canonical_flight_instance_id`.

More importantly, the production canonical identity implementation currently computes:

- stable structured leg identity from operating carrier/flight number, origin, original destination, initial service date and first scheduled gate-out UTC;
- SHA-256 over that structured identity;
- then retains only the **first 8 hexadecimal characters**;
- resulting ID format: `leg:<8 hex chars>`.

That is only a **32-bit deterministic SHA-256 prefix**. It is project-generated, but it is **not automatically treated as non-reconstructable** for a constrained flight-identity domain. The inventory therefore deliberately keeps both the raw-layer canonical-ID copy and the downstream canonical-ID class unresolved until the exact identity/retention design is repaired or proven.

Do **not** solve this by casually renaming it `derived_work`.

- canonical `flight_instance_id` non-reconstructability/design;
- webhook schedule-version provider values;
- webhook identity-resolution copied identity/date values;
- FIDS-population copied provider values outside the raw FIDS payload;
- semantic-event copied provider values;
- raw airborne observations;
- cleaned airborne rows that still preserve exact source values;
