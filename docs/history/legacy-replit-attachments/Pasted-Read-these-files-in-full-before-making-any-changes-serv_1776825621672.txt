Feature 1 — Refund Request

Show a simple confirmation dialog asking if they're sure
POST to a new endpoint /api/refund-request that takes the booking/payment ID
On the server, send two emails via SendGrid:

One to Hello@travnr.com with the subject "Refund Request — [User Name]" containing the user's name, email, booking reference, amount paid, and date of booking
One to the user with the subject "Your refund request is being reviewed" — warm, professional tone, tells them the Travnr team has received their request and will be in touch within 2 business days, signed off as "The Travnr Team"

Feature 2 — Full Flight Details on Proposal
When displaying flight options in proposal-detail.tsx, fetch and show the following from Duffel for each offer:

Cabin class (economy, business, etc.)
Baggage allowance — checked bags and carry-on, including weight limits if available
Seat information — whether seat selection is available and if there's a fee
Cancellation policy — whether the ticket is refundable, partially refundable, or non-refundable
Change/amendment policy — whether changes are allowed and any associated fees
Fare conditions in plain language if Duffel provides them

Display these as an expandable section under each flight option so the card doesn't get cluttered. Label it "Flight Details & Policies."
Feature 3 — Booking Confirmation Email
After a booking is successfully completed (after the Duffel order is created), send the user a confirmation email via SendGrid containing:

Subject: "Your booking is confirmed — [Route] on [Date]"
A warm thank you opening: "Thank you for booking with Travnr"
Their booking confirmation code (Duffel booking reference)
Full itinerary: origin, destination, departure date and time, arrival date and time, airline, flight number, cabin class
Passenger details
Total amount paid
A note that they can view their full itinerary in their Travnr dashboard
Signed off warmly as "The Travnr Team"

Use clean, professional HTML email formatting consistent with the existing verification emails in the codebase.
Feature 4 — Calendar Integration

The departure date, labelled as "[Airline] flight to [Destination]"
The return date if it's a round trip, labelled as "Return flight from [Destination]"
